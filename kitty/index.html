Kitty Data Collector♥

Artist Statement♥:
My creation is inspired by the classic game Piano Tiles. Players can train their reaction skills through simple left-and-right controls. The game is easy to start with, yet its difficulty increases gradually as you play. Collecting all items with quick responses brings a strong sense of achievement, and it also helps people relax and relieve stress.

I developed this game with the help of AI code assistance. I used AI to generate the basic game structure, then modified and adjusted the CSS styles in VS Code to create my own lovely Kitty theme. I also added personalized background music and sound effects to make the game more unique and complete.
